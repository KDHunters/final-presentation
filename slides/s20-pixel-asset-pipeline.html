반려동물 픽셀 에셋 생성 파이프라인

  1. 01

    비주얼 프롬프팅

    Visual Prompting

    반려동물 참조 이미지와 스타일, 격자, 자세 정보로 시각적 제약 조건 구성

  2. 02

    제약 조건 기반 이미지 생성

    Constraint-guided Generation

    외형적 특징과 서비스 디자인 스타일을 반영한 자세별 캐릭터 생성

  3. 03

    알고리즘 기반 후처리

    Algorithmic Post-processing

    격자 투영, 색상 추출, 외곽선 보정을 통해 32×32 픽셀 에셋으로 정규화

  4. 04

    다단계 자동 품질 검증

    Multi-stage Quality Validation

    판정 모델, 비전 모델을 활용해 정합성, 자세, 대칭성, 캐릭터 일관성 검증

  5. 05

    피드백 기반 재생성

    Closed-loop Regeneration

    통과시 최종 에셋 및 애니메이션 생성의 기준으로 활용, 실패시 재생성
