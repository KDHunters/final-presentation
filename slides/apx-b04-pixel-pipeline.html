StripeFoundry 픽셀 에셋 생성

번호 단계 입력 처리 출력
1 레퍼런스 포즈 생성 반려동물 사진 1장 같은 동물의 5자세를 한 장에 생성. 액세서리는 지움 5자세 시트
2 자르기·격자 5자세 시트 코드가 동물 영역 5개를 찾아 자름. 정면 자세의 키로 같은 칸 크기 격자를 정함 자세별 이미지 + 격자
3 픽셀 변환 자세별 이미지 + 격자 시각적 프롬프팅으로 모델이 그리고, 코드가 칸마다 대표 색 하나를 고름. 몸 바깥은 투명 32칸 픽셀 아트
4 자동 검수 픽셀 아트 자세 코드로 칸 단색·테두리 확인 후, Jev가 외곽선 밖 칸·얼굴 방향 판정. 탈락 자세만 최대 3회 재생성 통과한 자세
5 동작 생성 통과한 5자세 PixelLab으로 동작 프레임 생성 동작 6종
(대기·걷기·잠들기 등)
